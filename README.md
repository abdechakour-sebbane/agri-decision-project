# Smart Agriculture Decision Support System

## Team Roles & Folders
To avoid Git conflicts, please only edit files inside your assigned folders:
- **P1 (CNN & Severity):** Work inside `models/cnn/` and `app/pages/1_Upload.py`
- **P2 (LSTM & Rules):** Work inside `models/lstm/` and `data/`
- **P3 (Tree, Pipeline & Map):** Work inside `models/tree/`, `core/`, and `app/pages/2_Map.py`

## Setup Instructions
1. Clone the repository:
   `git clone <YOUR_REPO_URL>`
2. Create a virtual environment:
   `python -m venv venv`
   `source venv/Scripts/activate`  (Windows Git Bash)
3. Install dependencies:
   `pip install -r requirements.txt`
